## Not verifiable in the build sandbox

- **Real DNS.** The sandbox has no outbound DNS, so domains were mapped in `/etc/hosts` to test the success and private-address paths. On a normal machine, adding `https://www.edstellar.com` resolves for real.
- **Prisma CLI engine download.** The sandbox blocks `binaries.prisma.sh`, so the migration was generated and applied with Prisma's bundled schema engine (same engine version as CLI 7.10.1). On your machine `npx prisma migrate deploy` works as usual.
- **Vercel deployment** is part of phase 6.

## Known limitations of phase 1

- No crawling or checks yet; every monitoring screen except Overview, Websites and Settings is a placeholder naming its phase.
- Pausing a website records the setting; the scheduler that honours it arrives in phase 5.
- Users are created by an administrator with a temporary password; there is no email invitation or self-service reset (email delivery arrives with notifications in phase 5).
