## Problems found and fixed during verification

- **Timestamps 5½ hours off.** The local Postgres runs in Asia/Kolkata and the Prisma driver adapter sends timestamps without an offset, so every timestamp the app wrote was stored as local time. The app read them back consistently, but `now()` comparisons, chart day boundaries and other tools were wrong. Every Prisma client now pins `TimeZone=UTC` (`src/lib/prisma-adapter.ts`); existing rows were corrected by +5 h 30 min in one transaction. Demonstrated before/after: a noon-UTC timestamp was stored as 06:30 UTC without the setting and 12:00 with it.
- **DNS change noise.** Comparing exact addresses would have raised "DNS records changed" on nearly every run for Vercel; changes are now reported only when the host moves to a different /24 (IPv4) or /48 (IPv6).
- **TLS warning for IP hosts.** The SNI server name is no longer set for IP literals.

## Not verified

- No API endpoint is configured for this site, so API checks ran only against the local test server; the create/edit/delete forms were not submitted through a browser.
- Invalid and expiring certificates were tested locally, not against a real misconfigured site (badssl.com is blocked on this network).
